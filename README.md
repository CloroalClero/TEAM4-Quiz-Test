# Quiz EPICODE | Benchmark Exam (Build Week)

Web app single-page che simula l’esperienza del “Benchmark Exam” EPICODE: Welcome, quiz a tempo con domande a scelta multipla e schermata risultati.

## Live Demo
- GitHub Pages: https://michelbranche.github.io/Quiz-EPICODE/  <!-- [Inferenza] sostituisci con il link esatto che vedi in Settings → Pages -->

## Repository
- Codice: https://github.com/MichelBranche/Quiz-EPICODE

## Funzionalità principali
- Single-page flow: Welcome → Quiz → Results
- Domande a scelta multipla (una sola risposta)
- Timer per domanda con ring circolare
- Punteggio finale e schermata risultati
- UI responsive (desktop e mobile)

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Come eseguire in locale
Questo progetto è statico, quindi basta un server semplice.

### Opzione A: VS Code Live Server
1. Apri la cartella del progetto in VS Code
2. Installa l’estensione **Live Server**
3. Tasto destro su `index.html` → **Open with Live Server**

### Opzione B: server veloce (Node)
```bash
npx serve
